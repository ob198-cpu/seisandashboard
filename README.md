# 生産活動ダッシュボード

事業所別の合計作業時間、1人1報告日あたりの平均、活動別の時間配分、利用者別・日別の実績を確認する読取専用ダッシュボードです。

## 起動

1. Node.js 22以上をインストールします。
2. `config.example.json` を `config.local.json` として複製し、承認済みの各台帳のスプレッドシートIDを設定します。
3. `npm test` で集計テスト、`npm start` で起動します。
4. http://127.0.0.1:8797/ を開きます。

設定のIDはサーバー側のみで使用し、ブラウザーには返しません。設定ファイルはGit管理対象外です。取得先は既存台帳の Reports シート・N列のJSONです。現在の取得方式で閲覧できない台帳はエラー表示し、共有権限を自動変更しません。

## 操作

- 開始日・終了日を指定して「集計」。事業所名を押すと活動別・利用者別・日別の内訳を表示します。
- 活動別内訳は時間順と事業所横並びを切替できます。
- 比較指標を平均時間に切替できます。利用者名を押すと報告明細を表示します。

## 集計基準と保護

- 平均時間 = 報告作業時間の合計 ÷ 延べ報告人日。個人平均はその氏名の合計時間 ÷ 報告日数です。
- 氏名の完全一致による参考集計で、本人確認済みIDではありません。同姓同名は識別できず、表記違いは別人として計上されます。
- 報告作業時間には元記録の休憩・訓練等も含みます。未報告日を0時間とはしません。
- 氏名欠落時の平均、活動時間の内訳超過時の割合は算出を保留します。取得失敗と記録0件を区別します。
- 同名の活動でも事業所間の分類一致は保証せず、自動統合しません。
- 台帳はGETで読み取るだけです。GAS実行、台帳更新、初期化、削除、権限変更はしません。
- データはサーバーのメモリーにのみ保持し、終了すると消えます。台帳列を2回読み、一致した記録を集計します。
- 最短30秒の手動再取得制限、5分のキャッシュがあります。

## 公開運用について

このリポジトリはNodeサーバーを含み、GitHub Pagesだけでは動きません。初期設定はこのPC内からのみ接続できます。他のPCへの公開には、認証・事業所別認可・HTTPSを備えたサーバー構築が別途必要です。個人明細を含むため、単純に待受アドレスを外部へ開放しないでください。

実データ・台帳ID・認証情報をリポジトリに登録しないでください。既存SNS画面と事業所側システムは変更していません。
